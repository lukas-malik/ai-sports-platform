# AI SPORTS INTELLIGENCE PLATFORM

Osobní platforma pro sportovní analytiku, pravděpodobnostní predikce a hledání value na sázkovém trhu. Stav: discovery a architektura (září 2026). Master zadání a rozhodnutí z discovery jsou v Claude Projectu „AI SPORTS PLATFORM“.

Obsah repa:

- `collector/` sběr snapshotů tenisových kurzů z The Odds API (jediný kód schválený před dokončením Blueprintu, rozhodnutí D15).

Hlavní platforma vznikne až po schválení Blueprintu.
